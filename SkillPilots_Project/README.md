# SkillPilots – Career Path UI Demo

This is a front-end demonstration recreated from the screenshot supplied in the conversation.

## Run in VS Code
1. Extract `SkillPilots_Project.zip`.
2. Open the extracted `SkillPilots_Project` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension.
4. If using Live Server, right-click `index.html` and choose **Open with Live Server**.
5. Click **Steps** in the project card to open the Task Implementation Steps popup.
6. Use the moon button in the top bar to toggle dark mode.

## Files
- `index.html` – page layout and content
- `style.css` – responsive styling
- `script.js` – popup and theme interactions

## Important note
This is a static HTML/CSS/JavaScript recreation of the visible screenshot. It is **not** the original SkillPilots website source code and does not include its private backend, database, login, or live account features. The Render/Heroku instructions shown in the popup are example task text from the screenshot.
